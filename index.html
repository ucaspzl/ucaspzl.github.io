Research

AnchorPose for Geometry-Aware MOF Assembly through Meso-Grained Pose Generation

Zhonglong Peng, Rui Jiao, Chang Chen, Geng Zhong, Qiuliang Liu, Shifeng Jin

arXiv:2610.05843, 2026.10

We introduce AnchorPose, a geometry-aware framework for assembling periodic MOFs from given building blocks. It represents each block's pose through a small set of atoms with fixed identities, linking pose generation to the block's size and shape. Bayesian Flow Networks generate anchor coordinates, and rigid alignment recovers each block's position and orientation. The framework returns reconstructed anchors to subsequent generation steps, preserving internal block structure while generating the spatial arrangement between blocks.

PhaseMatcher: Autoregressive Phase-Set Identification with Spectral Decomposition

Zhonglong Peng, Qiuliang Liu, Chang Chen, Geng Zhong, Qi Li, Lihong Wang, Lan Jiang, Shifeng Jin

arXiv:2610.05844, 2026.10

We introduce PhaseMatcher, an autoregressive framework that combines phase prediction, spectral decomposition, and stopping decisions for multiphase PXRD analysis. After each phase prediction, the decomposition module jointly re-estimates all selected phase contributions and the residual using the original pattern and their reference patterns. The updated residual guides the next prediction, while a separate stopping module determines when to end identification.

EP-Flow: Disordered Crystal Structure Prediction without Site-Level Annotations

Qiuliang Liu, Liming Wu, Qi Li, Zhonglong Peng, Chang Chen, Xiaolong Chen, Wenbing Huang, Shifeng Jin

NeurIPS 2026

Formula-conditioned generation of disordered crystal structures. EP-Flow jointly generates occupancies, atomic coordinates, and lattice parameters through flow matching with composition and site-occupancy constraints.

Scientific data and software

CSDD: Crystal Structure and Diffraction Database

I contribute to CSDD, the Crystal Structure and Diffraction Database, which connects crystal structures and powder and single-crystal diffraction data with their source publications. It covers X-ray and neutron diffraction, with element-based search, interactive 3D structures, multiwavelength diffraction calculation, and data downloads. Researchers can upload powder patterns for peak detection and phase identification, or match structures using single-crystal cell parameters, then check the candidates against the linked structures, reference diffraction data, and publications.

CIF Editor

I contribute to CIF Editor, an agent for extracting crystallographic information from scientific literature and checking and editing CIF records. It assists with symmetry-constrained cell completion, checks on atomic coordinates and occupancies, and comparison against the source literature. Records are prepared for database ingestion after human review.

MatElab

I contribute to building MatElab, an electronic laboratory where researchers record experiments, manage research data, and use plugins to run analyses. I have also developed diffraction plugins on MatElab for file conversion, automatic peak detection, phase identification, and unit-cell matching. The accompanying record templates retain raw files and search settings, while the plugins write candidate tables, diffraction comparisons, and database links back to the same record for review. Experimental data can also be submitted for review and transferred to the database once approved.
