Scientific data and software

CSDD: Crystal Structure and Diffraction Database

I contribute to CSDD, a database linking crystal structures, powder and single-crystal diffraction data, and the original literature. It covers X-ray and neutron diffraction. The website supports element-based search, interactive 3D structure visualization, multiwavelength diffraction calculation, and data downloads.

Users can upload powder diffraction patterns for peak detection and phase identification, or match structures using single-crystal cell parameters. Candidate entries link to crystal structures, reference diffraction data, and source publications for comparison and review.

CIF Editor

I contribute to CIF Editor, an agent for extracting crystallographic information from scientific literature and checking and editing CIF records. It assists with symmetry-constrained cell completion, checks on atomic coordinates and occupancies, and comparison against the source literature. Records are prepared for database ingestion after human review.

MatElab diffraction plugins

MatElab is an electronic laboratory notebook and research data management platform. Its templates organize experimental records, while plugins process data and return results to the notebook.

I developed crystallographic diffraction plugins for file-format conversion, automatic peak detection, phase identification, and unit-cell matching. I designed the workflow that writes candidate tables, diffraction comparisons, and database links back to experimental records. The accompanying templates keep raw files, search settings, and analysis results together, with a separate submission step for human review before database ingestion.
